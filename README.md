# aqua-affecio-hacks-26

## AFFECIO — CHEMISTRY LAB

> **“Don't just match. Discover your chemistry.”**
>
> Match → Experience → Collaborate → Discover Chemistry → Connect

---

### The 7 Hackathon Experiences

1. **Liquid Glass Shared Lobby**: Futuristic, cinematic synchronized chamber for two users.
2. **Asymmetric Reactor (Hero Feature)**: 45-second high-stakes collaboration. User A holds recipe targets; User B holds controls. Neither can solve it alone.
3. **Synchronized Dilemma**: Scenario choices hidden until a dramatic `3 → 2 → 1` reveal.
4. **Deterministic Chemistry Engine**: Transparent, explainable scoring based on real telemetry (Teamwork, Sync, Adaptability, Balance). No fake random scores.
5. **Dynamic Fictional Compound**: Procedural chemical formula, orbital molecule visualizer, and lore.
6. **Collectible Chemistry Card**: 3D holographic tilt card with verified metrics and shareable link.
7. **Catalytic Conversation**: Authentic icebreakers generated directly from actual in-lab actions.

---

### Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

#### Hackathon Solo Demo Mode
Click **"⚡ Launch Instant Hackathon Demo Mode"** on the home screen or navigate to `/lab/DEMO-26?demo=true` to test the entire experience with the presenter control bar (toggle between Observer and Operator roles, simulate partner actions, and jump between stages).
